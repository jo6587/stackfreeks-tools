# Managed Database Cost Calculator

> Live: https://tools.stackfreeks.com/tools/managed-database-cost-calculator/

Estimate and compare monthly managed PostgreSQL/MySQL/Redis database pricing across Vultr Managed Databases, DigitalOcean Managed Databases, and AWS RDS — by RAM, storage, and HA standby replica.

## Features

- Compare estimated monthly cost across Vultr, DigitalOcean, and AWS RDS side by side
- Adjust RAM tier (1-32 GB), storage size, and HA/standby replica toggle
- Cheapest provider automatically highlighted
- "What managed saves you" summary (backups, patching, monitoring, failover)
- Vultr CTA with affiliate signup link
- EN/KO bilingual UI

## Tech Stack

- Pure HTML/CSS/JavaScript
- No build tools, no dependencies
- Deployed on Cloudflare Pages
