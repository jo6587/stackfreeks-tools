      정규식 골프 소개

      정규식 골프는 고전적인 프로그래밍 퍼즐입니다. 두 개의 문자열 목록이 주어지고, 첫 번째 목록의 모든 항목은 매치하면서 두 번째 목록은 하나도 매치하지 않는 정규식 하나를 작성해야 합니다. 핵심은 길이입니다. 점수는 패턴의 문자 수이며, 실제 골프처럼 점수가 낮을수록 좋습니다. 이 버전은 브라우저의 JavaScript RegExp 엔진으로 완전히 브라우저에서 실행되고, 난이도가 점점 높아지는 12개 레벨을 제공하며, 입력하는 동안 각 테스트 문자열 옆에 초록 체크 또는 빨간 X 를 표시해 어떤 경우가 아직 틀렸는지 바로 확인할 수 있습니다.

      레벨은 단순 리터럴 부분 문자열로 시작해 앵커 ^·$, [0-9]·[^aeiou] 같은 문자 클래스, 선택(alternation), 수량자 *·+·?·{n}, 룩어헤드, 마지막으로 (.)\1 같은 역참조까지 단계적으로 확장됩니다. 정규식을 배우거나 실무에서 까다로운 패턴을 작성하기 전에 몸을 푸는 데 좋은 방법입니다. 가입도, 답안 추적도 없으며, 최고 기록은 본인 브라우저에만 저장됩니다.

      플레이 방법

      Step 1
      문제 읽기
      각 레벨은 규칙을 설명하고 두 목록을 보여줍니다: 정규식이 매치해야 하는 문자열과 거부해야 하는 문자열.
      Step 2
      패턴 입력
      슬래시 사이에 정규식을 입력하세요. 각 테스트 문자열에 실시간으로 초록 체크 또는 빨간 X 가 표시됩니다. 필요하면 i, m, g 플래그를 켜세요.
      Step 3
      풀고 나서 줄이기
      매치·거부 항목이 모두 초록이 되면 레벨 통과입니다. 점수는 문자 수이므로 넘어가기 전에 최대한 줄여 보세요.
      Step 4
      12개 전부 클리어
      다음 레벨 버튼으로 진행합니다. 마지막에 총 사용 문자 수와 레벨당 평균이 표시되고, 최고 완주 기록은 로컬에 저장됩니다.

      자주 묻는 질문

      정규식 골프는 한 목록의 모든 문자열은 매치하고 두 번째 목록은 하나도 매치하지 않는, 가능한 한 짧은 정규식을 작성하는 퍼즐입니다. 골프처럼 점수가 낮을수록 이기며, 점수는 패턴의 문자 수입니다. 각 레벨마다 어떤 기능(앵커, 문자 클래스, 선택, 수량자)이 규칙을 가장 간결하게 표현하는지 고민하게 만들기 때문에 정규식 연습에 인기가 많습니다.
      여기 레벨처럼 작고 집중된 문제로 연습하고, 하나를 풀 때마다 더 짧게 만들어 보세요. 핵심 구성 요소를 순서대로 익히세요: 리터럴, 앵커 ^ 와 $, [a-z]·[^aeiou] 같은 문자 클래스, 파이프를 이용한 선택, 수량자 * + ? 와 {n}, 그룹, 룩어헤드, 역참조. 남들의 짧은 풀이를 읽고, 치트 시트를 곁에 두고, 통과해야 하는 문자열뿐 아니라 실패해야 하는 문자열로도 항상 테스트하세요.
      정답이 하나로 정해진 경우는 드뭅니다. 가장 짧은 정규식은 두 목록에 전적으로 달려 있습니다. 매치 목록과 거부 목록을 구분하기만 하면 되므로, 완전히 앵커링된 정밀한 표현보다 단일 리터럴 부분 문자열이 더 나을 때가 많습니다. 매치해야 하는 모든 문자열에는 있고 거부해야 하는 문자열에는 없는 문자나 시퀀스를 찾으세요. 골프에서 느슨한 패턴이 엄격한 패턴보다 점수가 좋은 이유입니다.
      최소 패턴을 찾는 습관은 유용하지만, 골프식 사고방식은 그렇지 않습니다. 실무 정규식은 읽기 쉽고, 중요한 곳에 앵커가 있으며, 엣지 케이스와 파국적 백트래킹에 안전해야 합니다. 문자 몇 개가 늘더라도 말이죠. 정규식 골프는 각 기능이 무엇을 하고 패턴이 어떻게 결합되는지 배우는 연습장으로 쓰고, 실제 코드에서는 명확하고 주석이 잘 달린 표현을 작성하세요.
      이 게임은 브라우저에 내장된 JavaScript 정규식 엔진을 RegExp 생성자로 사용합니다. 즉 ECMAScript 문법입니다: 문자 클래스, 선택, 탐욕적·게으른 수량자, 캡처 그룹, \1 같은 역참조, 룩어헤드가 모두 지원되고 최신 브라우저에서는 룩비하인드도 동작합니다. 소유 수량자나 재귀 같은 Perl·PCRE 확장은 없습니다. i, m, g 플래그를 켤 수 있으며, g 는 매치 테스트 결과를 바꾸지 않지만 참고용으로 표시됩니다.
