왼쪽에 마크다운을 작성하면 오른쪽에 실시간으로 렌더링됩니다. HTML 출력을 복사하거나 툴바로 서식을 빠르게 삽입하세요.

사용 방법

1. 마크다운 입력

왼쪽 에디터에 작성하세요. 오른쪽 미리보기가 키 입력마다 즉시 업데이트됩니다.

2. 툴바 활용

툴바 버튼을 클릭해 굵게, 기울임, 제목, 링크, 목록 등 서식을 빠르게 삽입하세요.

3. HTML 복사

"HTML 복사" 버튼을 클릭하면 렌더링된 HTML이 클립보드에 복사됩니다.

4. 초기화

지우기 버튼을 누르면 에디터와 미리보기가 모두 초기화되어 새 문서를 작성할 수 있습니다.

자주 묻는 질문

GFM(GitHub Flavored Markdown)을 지원합니다 — 제목, 굵게, 기울임, 목록, 링크, 이미지, 표, 코드 블록, 인용구, 수평선 등이 포함됩니다.
현재는 지원하지 않습니다. 코드 블록은 렌더링되지만 언어별 색상 강조는 없습니다.
네 — .md 파일을 텍스트 에디터에서 열고, 전체 선택 후 왼쪽 에디터에 붙여넣기 하면 됩니다.
아니요 — 내용은 탭이 열려 있는 동안 브라우저에만 존재합니다. 서버로 전송되지 않으며, 닫기 전에 복사해 두세요.
