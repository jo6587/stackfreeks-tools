HTTP 상태 코드 퀴즈

HTTP 상태 코드를 얼마나 잘 아는지 테스트하세요. 15개의 혼합 문제 — 429나 502 같은 코드를 의미와 연결하고, 실제 상황을 알맞은 코드와 연결합니다. 즉시 해설과 치트 시트를 제공합니다.

HTTP 상태 코드 치트 시트

2xx Success

200OK요청이 성공했습니다.
201Created요청이 성공했고 새 리소스가 생성되었습니다.
202Accepted요청이 처리를 위해 접수되었지만 아직 완료되지 않았습니다.
204No Content성공했지만 본문에 반환할 내용이 없습니다.

3xx Redirection

301Moved Permanently리소스가 새 URL로 영구 이동했습니다.
302Found리소스가 일시적으로 다른 URL에 있습니다.
304Not Modified캐시된 사본이 여전히 유효하며 본문은 전송되지 않습니다.
307Temporary Redirect임시 리디렉션이며 요청 메서드를 바꾸면 안 됩니다.
308Permanent Redirect영구 리디렉션이며 요청 메서드를 바꾸면 안 됩니다.

4xx Client Error

400Bad Request잘못된 문법 등 클라이언트 오류로 서버가 요청을 처리할 수 없습니다.
401Unauthorized인증이 필요하거나 인증에 실패했습니다.
403Forbidden서버가 요청을 이해했지만 인가를 거부합니다.
404Not Found서버가 요청한 리소스를 찾을 수 없습니다.
405Method Not Allowed이 리소스에 대해 해당 HTTP 메서드가 허용되지 않습니다.
409Conflict요청이 리소스의 현재 상태와 충돌합니다.
410Gone리소스가 전달 주소 없이 영구히 사라졌습니다.
418I'm a teapot만우절 농담 코드: 서버가 찻주전자라서 커피 내리기를 거부합니다.
422Unprocessable Content문법은 유효하지만 내용이 의미상 올바르지 않습니다.
429Too Many Requests클라이언트가 일정 시간 동안 너무 많은 요청을 보냈습니다(속도 제한).

5xx Server Error

500Internal Server Error서버가 예기치 않은 상황을 만나 요청을 완료하지 못했습니다.
502Bad Gateway게이트웨이 역할의 서버가 업스트림 서버로부터 잘못된 응답을 받았습니다.
503Service Unavailable서버가 일시적으로 과부하 상태이거나 점검 중입니다.
504Gateway Timeout게이트웨이가 업스트림 서버로부터 제때 응답을 받지 못했습니다.

HTTP 상태 코드 퀴즈 소개

HTTP 상태 코드는 서버가 모든 응답과 함께 반환하는 세 자리 숫자이며, 이를 외워두면 API와 웹 앱 디버깅이 훨씬 빨라집니다. 이 퀴즈는 실무에서 실제로 자주 등장하는 23개 코드에 집중합니다 — 2xx 성공 코드, 3xx 리디렉션, 401·403·404·429 같은 4xx 클라이언트 오류, 그리고 500·502·503·504 같은 5xx 서버 오류입니다.

각 문제는 코드를 보여주고 의미를 묻거나, 실제 상황을 설명하고 어떤 코드가 맞는지 묻습니다. 오답 보기는 번호가 가까운 코드에서 뽑히므로 범위로 찍는 대신 302와 307을 실제로 구분할 수 있어야 합니다. 모든 답변 뒤에는 쉬운 설명이 따라오고, 치트 시트에는 23개 코드가 클래스별로 정리되어 있습니다. 전부 브라우저에서 실행되며 가입이 필요 없고 최고 점수는 로컬에 저장됩니다.

퀴즈 사용 방법

Step 1
퀴즈 시작
퀴즈 시작을 누르세요. 가장 흔한 23개 HTTP 상태 코드에서 무작위로 뽑은 15문제가 출제됩니다.
Step 2
문제 풀기
두 형식이 섞여 나옵니다: 제시된 코드의 의미를 고르거나, 설명된 상황에 맞는 코드를 고릅니다. 네 개의 보기 중 하나를 탭하세요.
Step 3
해설 확인
답하면 정답이 초록색으로 바뀌고 코드의 실제 의미를 한 줄로 설명합니다. 다음을 누르세요.
Step 4
점수 확인
마지막에 15점 만점의 점수가 나오고 최고 기록이 저장됩니다. 치트 시트를 열어 모든 코드를 복습하세요.

자주 묻는 질문

401 Unauthorized는 요청에 유효한 인증 정보가 없다는 뜻입니다 — 서버가 당신이 누구인지 모르며, 올바른 인증 정보를 보내면 해결될 수 있습니다. 403 Forbidden은 서버가 당신이 누구인지는 알지만 접근을 거부한다는 뜻입니다 — 계정 자체에 권한이 없으므로 다시 로그인해도 소용이 없습니다. 요약하면 401은 "인증하라", 403은 "인증은 됐지만 허용되지 않는다"입니다.
셋 다 서버 측 5xx 오류입니다. 502 Bad Gateway는 프록시나 게이트웨이가 연결하려던 업스트림 서버로부터 잘못된 응답을 받았다는 뜻입니다. 503 Service Unavailable은 서버 자체가 일시적으로 요청을 처리할 수 없다는 뜻으로, 보통 과부하나 점검 때문입니다. 504 Gateway Timeout은 게이트웨이나 프록시가 업스트림 서버로부터 제때 응답을 받지 못했다는 뜻입니다. 502와 504는 프록시 뒤의 백엔드가 고장났거나 느리다는 신호이고, 503은 앞단 서버가 지금은 감당할 수 없다고 알리는 것입니다.
301 Moved Permanently는 URL이 완전히 바뀌었고 검색엔진이 순위를 새 주소로 옮기길 원할 때 사용합니다. 브라우저와 크롤러가 캐시합니다. 302 Found는 원래 URL이 돌아올 임시 리디렉션에 사용합니다. 301과 302는 역사적으로 리디렉션 시 클라이언트가 메서드를 GET으로 바꾸는 것을 허용했습니다. 308 Permanent Redirect는 원래 HTTP 메서드와 본문을 유지하는 영구 리디렉션이 필요할 때, 예를 들어 POST를 GET으로 낮추지 않고 리디렉션할 때 사용합니다.
429 Too Many Requests는 일정 시간 동안 너무 많은 요청을 보내 서버가 속도를 제한하고 있다는 뜻입니다. 할당량보다 빠르게 API를 호출할 때 흔히 발생합니다. 응답에는 몇 초를 기다려야 하는지 알려주는 Retry-After 헤더가 포함되는 경우가 많습니다. 해결 방법은 속도를 늦추고, 재시도 사이에 백오프를 넣고, 응답을 캐시하거나, 더 높은 속도 제한을 요청하는 것입니다.
IANA HTTP 상태 코드 레지스트리에는 다섯 클래스에 걸쳐 약 70개의 코드가 등록되어 있습니다: 1xx 정보, 2xx 성공, 3xx 리디렉션, 4xx 클라이언트 오류, 5xx 서버 오류입니다. 일상적인 웹 개발에서는 약 20~25개만 알면 됩니다. 이 퀴즈는 실제 API와 웹 앱에서 가장 자주 등장하는 23개 코드를 훈련합니다.
