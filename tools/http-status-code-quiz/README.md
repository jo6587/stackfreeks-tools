# HTTP Status Code Quiz

> Live: https://tools.stackfreeks.com/tools/http-status-code-quiz/

Learn HTTP status codes by quiz. 15 questions per round — match a code to its
meaning or pick the right code for a real-world scenario — with instant
explanations and a full cheat sheet.

## Features

- Two question types: "what does 429 mean?" and "which code fits this situation?"
- ~23 status codes covered (200/201/204/301/302/304/307/308/400/401/403/404/405/409/410/418/422/429/500/502/503/504)
- Instant per-answer explanation, score, streak, and personal best (localStorage)
- Collapsible cheat sheet grouped by status class
- EN / KO bilingual

## Tech Stack

- Pure HTML/CSS/JavaScript
- No build tools, no dependencies
- Deployed on Cloudflare Pages
