키보드 테스터 소개

이 무료 온라인 키보드 테스터는 다운로드나 가입 없이 브라우저에서 바로 모든 키를 테스트할 수 있습니다. 키를 누르면 화면 키보드의 해당 키캡이 액센트 색으로 반짝인 뒤 옅게 표시되어, 이미 확인한 키를 한눈에 볼 수 있습니다. "42 / 104 키 테스트됨" 카운터로 전체 키를 다 확인했는지 알 수 있습니다.

키보드를 교환(RMA)하거나 분해하기 전에 의심되는 결함을 가장 빠르게 진단하는 방법입니다. 전혀 켜지지 않는 키는 스위치나 컨트롤러 고장, 손을 뗀 뒤에도 켜져 있거나 저절로 반복되는 키는 전형적인 눌림 고착·채터링 증상입니다. 여러 키를 동시에 누르면 고스팅인지 진짜 N키 롤오버인지 확인할 수 있습니다. 풀사이즈, TKL, 75%, 65%, 60% 레이아웃 프리셋으로 실제 사용하는 키보드에 맞게 테스트 개수를 맞춥니다.

키보드 테스터 사용 방법

1. 레이아웃 선택

Full, TKL, 75%, 65%, 60% 중 선택해 화면 키보드와 테스트 개수를 실제 키보드에 맞춥니다.

2. 클릭해서 시작

키보드 영역을 클릭해 포커스합니다. 오버레이가 사라지고 키 입력이 인식됩니다.

3. 모든 키 누르기

한 줄씩 눌러보세요. 누른 키는 켜지고 테스트됨으로 표시됩니다. 여러 키를 동시에 눌러 롤오버도 확인하세요.

4. 결과 확인

key / code / keyCode 값과 눌림 고착 힌트를 확인하세요. Reset으로 초기화 후 다시 테스트합니다.

자주 묻는 질문

화면 키보드를 클릭해 테스터를 시작한 뒤 키를 하나씩 눌러보세요. 누른 키는 켜지고 "테스트됨"으로 옅게 표시되며, 카운터가 현재 레이아웃에서 몇 개를 확인했는지 보여줍니다. 문자, 숫자, 조합키, 펑션 열, 방향키, 넘패드 순서로 체계적으로 눌러 100%가 될 때까지 진행하세요. 마지막으로 누른 키의 event.key, event.code, keyCode 값도 실시간으로 표시되어 리맵 디버깅에 유용합니다.
각 키를 평소처럼 눌렀다 떼면서 readout을 확인하세요. 정상 키는 keydown 한 번, keyup 한 번을 기록합니다. 고착되거나 채터링되는 키는 손을 뗀 뒤에도 켜져 있거나, 저절로 빠르게 반복되거나, 한 번 눌렀는데 여러 번 입력됩니다. 이 테스터는 약 10초 이상 눌려 있는 키를 고착 의심으로 표시하지만 이는 소프트웨어 휴리스틱일 뿐이며, 실제로 고착된 스위치나 디바운스 결함은 접점 세정제나 스위치 교체가 필요합니다.
고스팅은 여러 키를 동시에 눌렀을 때 누르지 않은 키가 입력되거나 누른 키가 누락되는 현상으로, 키보드 매트릭스가 해당 조합을 구분하지 못해 발생합니다. N키 롤오버(NKRO)는 모든 키가 독립적으로 스캔되어 몇 개든 동시에 눌러도 인식되는 것을 뜻합니다. 테스트하려면 화면 레이아웃에서 여러 키를 동시에 눌러 보세요 — 이 테스터는 새 키를 누를 때 이전 키를 지우지 않고 모두 활성 상태로 유지하므로, 어떤 조합이 올바르게 인식되는지 볼 수 있습니다.
일부 키 입력은 브라우저에 전달되지 않습니다. 운영체제나 브라우저가 예약한 키 — 스크린샷 키, 미디어 키, 하드웨어에서 처리되는 Fn 조합, Ctrl+W 같은 단축키 — 는 페이지에 도달하기 전에 가로채집니다. 또한 테스터가 포커스되어 있어야 하므로 먼저 키보드를 클릭하세요. 그 뒤에도 일반 문자·숫자 키가 반응하지 않는다면 해당 스위치나 키보드 컨트롤러의 하드웨어 결함일 가능성이 높습니다.
키보드 위의 레이아웃 선택기로 사용하는 보드에 맞추세요 — Full (104), TKL (87), 75%, 65%, 60%. 화면 레이아웃과 "테스트됨" 합계가 그에 맞게 바뀌므로, 60% 보드는 61키에서, 풀사이즈는 넘패드를 포함해 104키 전부를 눌러야 완료됩니다. 실제 키보드와 같은 레이아웃을 선택해야 카운터가 실제 커버리지를 반영합니다.
