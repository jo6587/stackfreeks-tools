언어 기억력 테스트 소개

이 언어 기억력 테스트는 Human Benchmark로 널리 알려진 "몇 개의 단어를 기억할 수 있는가" 챌린지입니다. 한 번에 한 단어가 표시됩니다. 초반에는 대부분 처음 보는 단어이므로 NEW를 누르고, 그 단어는 "본 단어" 목록에 조용히 추가됩니다. 판이 진행되면 단어가 반복되기 시작하고, 그것을 알아보고 SEEN을 눌러야 합니다. 정답마다 1점씩 올라가고, 오답(반복된 단어를 NEW로, 새 단어를 SEEN으로)마다 생명 3개 중 하나를 잃습니다. 3개가 모두 사라지면 게임이 끝나고 점수가 표시됩니다.

단어 목록은 영어로 고정되어 있습니다. 이것이 이 테스트의 표준 방식이며, KO 사용자도 단어의 뜻을 알 필요 없이 "전에 나왔는지"만 판단하면 됩니다. 툴은 본 단어 전체를 JavaScript Set에 저장하고, 목록이 커질수록 반복 단어를 더 자주 보여주는 간단한 휴리스틱으로 다음 단어를 고르며, 최고 점수는 localStorage로 브라우저에만 저장합니다. 마우스·터치·키보드 모두 지원하고 가입이 필요 없으며 전부 브라우저에서 실행됩니다. 평균은 약 40점, 꾸준히 60점을 넘기면 우수한 편입니다.

언어 기억력 테스트 사용 방법

1. 판 시작

Start를 누르세요. 박스 중앙에 단어 하나가 나타나고 위에 생명 3개가 표시됩니다.

2. 각 단어 판단

이번 판에서 처음 보는 단어면 NEW, 전에 나온 적 있으면 SEEN을 누르세요. 버튼을 쓰거나, NEW는 왼쪽 화살표·K, SEEN은 오른쪽 화살표·L.

3. 생명 지키기

정답마다 1점. 오답마다 생명 하나. 생명 3개가 모두 사라질 때까지 계속됩니다.

4. 결과 확인

생명이 0이 되면 점수, 비교(평균 약 40, 60 이상이면 우수), 저장된 최고 기록이 표시됩니다. Try again으로 새 판을 시작하세요.

자주 묻는 질문

이 방식의 테스트에서는 40점대가 성인 평균 정도입니다. 50~70점이면 좋은 결과이고, 70~80점 이상이면 보통 단어를 그룹으로 묶거나 반복 패턴을 파악하는 등의 전략을 쓰고 있는 것입니다. 단어 풀이 한정되어 있어 아주 높은 점수는 순수한 기억력보다 집중력과 지구력에도 좌우됩니다.
언어 작업기억과 재인기억을 측정합니다. 점점 늘어나는 단어 목록을 머릿속에 유지하면서 새 단어가 이미 본 것인지 빠르게 판단하는 능력입니다. 후반의 한 번의 실수로 판이 끝나므로 지속적 주의력도 함께 측정합니다. 임상 기억 검사는 아니지만 몇 분간 언어 정보를 얼마나 잘 유지하는지에 대한 합리적인 지표입니다.
가벼운 플레이어의 평균은 약 40개 정답입니다. 대부분 25~55점 사이입니다. 페이스 조절과 기억 전략을 익히면 점수가 올라가고, 피곤하거나 산만하거나 서두르면 떨어집니다. 한 번의 결과는 대략적인 스냅샷으로 보고, 남과 비교하기보다 자신의 점수 변화를 추적하세요.
단기적으로는 연습이 도움이 됩니다. 속도를 늦추고 각 단어를 꼼꼼히 읽으며, 평평한 목록을 통째로 외우기보다 작은 묶음으로 그룹화하세요. 장기적으로는 뇌 훈련 앱보다 수면, 유산소 운동, 분산 주의 줄이기(알림 줄이기, 한 번에 한 가지)가 작업기억에 더 효과적입니다. 꾸준한 독서와 새 어휘 학습도 언어 회상력을 유지해 줍니다.
Human Benchmark로 알려진 이 테스트의 표준 버전은 점수를 서로 비교할 수 있도록 고정된 common 영어 단어 풀을 사용합니다. 저희도 같은 이유로 영어 단어 목록을 유지하며, 언어를 바꾸면 단어 길이와 친숙도가 달라져 결과를 비교할 수 없게 됩니다. 영어가 모국어가 아니어도 테스트할 수 있습니다. 단어가 전에 나왔는지 알아보는 데는 뜻을 알 필요가 없습니다.
