# Aim Trainer

> Live: https://tools.stackfreeks.com/tools/aim-trainer/

A browser aim trainer — click targets as fast as you can and measure your average milliseconds per target, accuracy and total time. Human Benchmark "Aim Trainer" style.

## Features

- Random-spawn circular targets inside a contained play area
- Selectable target count: 10 / 30 / 50
- Timer starts on first hit, stops on the last target
- Headline metric: average time per target (ms), plus total time, misses and accuracy
- Qualitative band (elite / strong / solid / casual / slow) with context
- Per-count best average saved to localStorage (`aim-best-<count>`)
- Responsive target size (44–64px), mouse + touch via Pointer Events
- EN / KO bilingual, no signup, runs entirely in the browser

## Tech Stack

- Pure HTML/CSS/JavaScript
- No build tools, no dependencies
- Deployed on Cloudflare Pages
