사용 방법

1. HEIC 파일 선택

드롭 존을 클릭하거나 .heic 파일을 드래그 앤 드롭하세요. 여러 파일을 동시에 선택할 수 있습니다.

2. 품질 조정 (선택사항)

기본값 92%는 선명도와 파일 크기의 균형이 좋습니다. 파일 크기를 줄이려면 슬라이더를 낮게 조정하세요.

3. 변환된 JPG 미리보기

변환된 각 이미지가 썸네일 미리보기와 변환 전후 파일 크기 비교와 함께 카드로 표시됩니다.

4. 다운로드

각 카드에서 개별 다운로드하거나 '전체 다운로드' 버튼으로 일괄 내보내기 하세요. 파일은 서버에 업로드되지 않습니다.

자주 묻는 질문

HEIC(High Efficiency Image Container)는 iOS 11부터 iPhone의 기본 사진 포맷입니다. HEIF 표준을 사용하여 JPG의 약 절반 크기로 유사한 화질을 제공합니다. Apple이 기기 저장 공간을 절약하기 위해 도입했지만, Apple 생태계 외부에서는 범용적으로 지원되지 않습니다.
Windows와 Android는 HEIC 포맷을 기본적으로 지원하지 않습니다. Windows 10/11에서는 Microsoft Store에서 'HEIC 이미지 확장' 코덱을 설치할 수 있지만, 많은 앱에서 여전히 인식하지 못합니다. Android 갤러리 앱도 대부분 HEIC를 지원하지 않습니다. HEIC를 JPG로 변환하는 것이 모든 플랫폼에서 호환성을 보장하는 가장 확실한 방법입니다.
JPG가 손실 압축을 사용하기 때문에 약간의 화질 저하가 있을 수 있지만, 기본값 92% 품질에서는 육안으로 거의 구별할 수 없습니다. 슬라이더를 100%로 올리면 더 큰 파일 크기지만 최상의 화질을 얻을 수 있습니다. 92% 품질로 변환된 JPG는 원본 HEIC보다 파일 크기가 10~30% 정도 커지는 경향이 있습니다.
네, 완전히 무료이며 파일 크기 제한이 없습니다. 변환이 heic2any 라이브러리를 사용하여 브라우저에서 직접 실행되므로, 유일한 제한은 기기의 가용 메모리입니다. 어떤 iPhone 모델의 고화질 HEIC 사진도 계정 생성 없이 제한 없이 변환할 수 있습니다.
네. 드롭 존을 클릭하고 Shift 또는 Cmd/Ctrl을 누른 채 여러 파일을 선택하거나, HEIC 파일을 드롭 존으로 일괄 드래그하세요. 각 파일이 병렬로 변환되며 개별 미리보기 카드로 표시됩니다. 모든 변환이 완료되면 '전체 다운로드' 버튼이 나타납니다.
