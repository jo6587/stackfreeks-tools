사용 방법

1. 콘텐츠 입력

URL, 텍스트, 이메일, 전화번호 등을 입력창에 입력하거나 붙여넣으세요.

2. 옵션 설정

크기(소/중/대), 오류 수정 레벨, 전경색·배경색을 자유롭게 설정하세요.

3. 실시간 미리보기

입력하는 즉시 QR 코드가 자동 생성됩니다. 별도 버튼 클릭이 필요 없습니다.

4. PNG 또는 SVG 다운로드

PNG는 인쇄용에, SVG는 크기 조절이 자유로워 디자인 작업에 적합합니다.

자주 묻는 질문

오류 수정은 QR 코드가 일부 손상되거나 가려진 경우에도 인식되도록 합니다. L은 7% 복구로 깨끗한 화면 표시에 적합하고, M(15%)은 기본값으로 대부분의 용도에 맞습니다. Q(25%)는 긁힘이 생길 수 있는 표면에, H(30%)는 로고를 QR 코드 위에 겹칠 때 적합하지만 코드가 더 조밀해집니다.
네, 완전 무료입니다. 이 도구는 오픈소스 라이브러리를 사용해 브라우저에서 직접 QR 코드를 생성합니다. 워터마크, 구독, 계정, 사용 제한이 전혀 없습니다. 다운로드한 PNG 및 SVG 파일은 깨끗하게 바로 사용할 수 있습니다.
대부분의 인쇄물에는 Large(1024px)를 선택하여 최고 해상도를 확보하세요. 일반적으로 QR 코드는 인쇄 시 최소 2cm × 2cm 이상이어야 하며, 스캔 거리는 코드 너비의 10배를 넘지 않아야 합니다. 대형 포스터나 현수막에는 SVG로 내보내어 품질 손실 없이 원하는 크기로 확대하세요.
가능합니다. 전경색 선택기로 모듈(점) 색상을, 배경색 선택기로 여백 영역 색상을 변경하세요. 스캐너가 코드를 인식하려면 두 색상 사이의 명도 대비가 최소 4:1 이상이어야 합니다. 전경과 배경이 너무 가깝지 않도록 주의하세요.
전체 URL(https:// 포함)을 입력창에 붙여넣으면 QR 코드가 즉시 생성됩니다. HTTPS URL을 사용하고 가능한 짧게 유지하는 것이 좋습니다. URL이 짧을수록 더 단순하고 스캔하기 쉬운 코드가 만들어집니다. 코드 밀도를 줄이려면 URL 단축 서비스를 먼저 사용하세요.
