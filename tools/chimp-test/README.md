# Chimp Test

> Live: https://tools.stackfreeks.com/tools/chimp-test/

Memorize the positions of numbered tiles, then click them back in ascending order after they're hidden — the memory task a chimpanzee once beat human adults at.

## Features

- Numbered tiles flash briefly on a 5x5 grid, then get masked to look identical
- Click tiles back in ascending order (1, 2, 3...) purely from memory
- Each successful round adds one more numbered tile
- Wrong click ends the run and reveals the correct layout
- Best round tracked locally via `localStorage` — no account, no server
- EN/KO bilingual UI

## Tech Stack

- Pure HTML/CSS/JavaScript
- No build tools, no dependencies
- Deployed on Cloudflare Pages
