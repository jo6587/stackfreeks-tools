사용 방법

STEP 1

보호할 서비스 선택

서버에서 실행 중인 데몬을 체크하세요 — 모든 VPS에서 sshd는 필수입니다. 웹사이트를 운영하면 Nginx/Apache jail을, 메일·FTP는 postfix/vsftpd를 추가하세요.

STEP 2

차단 정책 조정

maxretry(허용 실패 횟수), bantime(차단 유지 시간), findtime(집계 시간 창)을 설정하세요. 기본값 3 / 1h / 10m이 대부분의 서버에 적합합니다.

STEP 3

내 IP 화이트리스트

집이나 사무실 IP를 ignoreip에 추가해 스스로 차단되는 일을 방지하세요 — 영구 차단을 선택했다면 특히 중요합니다.

STEP 4

설치 후 적용

생성된 파일을 /etc/fail2ban/jail.local에 저장하고 명령어를 실행하세요: fail2ban 설치, 서비스 재시작, fail2ban-client status로 확인.

자주 묻는 질문

대부분의 VPS에는 1시간(1h)이 무난한 기본값입니다 — 브루트포스 스크립트를 막기에 충분하고, 비밀번호 오타 정도는 용서할 만큼 짧습니다. 중요한 서버는 24h 또는 1w를 많이 사용합니다. 영구 차단(bantime = -1)은 공격적이므로 반드시 ignoreip를 올바르게 설정한 뒤 사용하세요.
maxretry는 findtime 시간 창 안에서 허용되는 실패 횟수입니다. maxretry = 3, findtime = 10m이면 10분 안에 3번 로그인 실패 시 해당 IP가 차단됩니다. 값이 낮을수록 엄격하며 SSH에는 3~5가 일반적입니다.
jail.local의 [DEFAULT] 섹션 ignoreip에 내 IP나 서브넷을 추가하세요. 예: ignoreip = 127.0.0.1/8 ::1 203.0.113.42. 이 목록의 주소는 절대 차단되지 않습니다. 유동 IP라면 ISP 서브넷을 등록하거나 고정 IP VPN을 사용하세요.
네. fail2ban은 기존 방화벽 위에 자체 차단 규칙을 추가합니다 — 기본은 iptables(최신 배포판은 nftables)입니다. ufw가 켜진 Ubuntu에서도 바로 동작하며, banaction = ufw로 설정하면 차단이 ufw 규칙으로 관리됩니다. ufw는 고정 정책, fail2ban은 동적 차단으로 서로 보완합니다.
sudo fail2ban-client set sshd unbanip 203.0.113.42 를 실행하세요 (jail 이름과 IP는 실제 값으로 교체). 현재 차단 목록은 sudo fail2ban-client status sshd로 확인합니다. fail2ban 0.10+에서는 sudo fail2ban-client unban [IP]로 모든 jail에서 한 번에 해제할 수 있습니다.
