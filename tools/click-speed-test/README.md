# Click Speed Test

> Live: https://tools.stackfreeks.com/tools/click-speed-test/

A free click speed test (CPS test) — click a pad as fast as you can and see your clicks per second, total clicks, and a rank.

## Features

- Duration selector: 1s / 5s (default) / 10s / 30s / 60s / 100s
- Timer starts on the first click; live remaining time + running click count
- Result: CPS (2 decimals), total clicks, and a rank label (Slow / Average / Good / Fast / Insane)
- Best CPS per duration saved to `localStorage` (`cps-best-<dur>`)
- Mouse + touch via `pointerdown`; clicks outside the pad are ignored
- Bilingual EN / KO, How-to guide, FAQ, JSON-LD (WebApplication + FAQPage)

## Tech Stack

- Pure HTML/CSS/JavaScript
- No build tools, no dependencies
- Deployed on Cloudflare Pages
